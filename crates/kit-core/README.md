# Slint Kit Core

Strict domain values and state machines for [Slint Kit](https://github.com/damione1/slint-kit): exact decimal and money arithmetic, civil dates, typed fields, stable keyed selection, focus, overlays and generation guards. This crate has no UI backend.

```toml
[dependencies]
slint-kit-core = "0.1"
```

For applications, start with the [`slint-kit` facade](https://crates.io/crates/slint-kit) and [`slint-kit-build`](https://crates.io/crates/slint-kit-build). Rust 1.92 or later is required.
